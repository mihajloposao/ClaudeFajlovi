# Prica1 — radni folder romana

Radna verzija: **srpski**. Prevod na engleski dolazi tek kad rukopis bude zavrsen.
Ciljani obim: **roman, 80.000+ reci**.

## Kako se ovaj folder koristi

Chat se zaboravlja. Fajlovi ne. **Svaka odluka koja se donese u razgovoru mora zavrsiti u nekom fajlu**,
inace ne postoji. Ovo je pravilo bez izuzetka.

**Drugo pravilo, jednako vazno:** razlikovati odluceno od pretpostavljenog.
Nista se ne upisuje kao zakon price dok Mihajlo to izricito ne potvrdi. Sve ostalo —
ukljucujuci i ono sto logicno "sledi" iz neke odluke — ide u `00-BIBLIJA/otvorena-pitanja.md`.
Bolje postaviti pitanje nego izvesti zakljucak.

## Struktura

```
00-BIBLIJA/     ← izvor istine. Sve sto je odluceno o prici.
  premisa.md         Premisa, tema, centralno pitanje. Prvo se popunjava.
  likovi.md          Svaki lik: zelja, potreba, mana, luk, detalji, nacin govora.
  svet.md            Mesto, vreme, pravila sveta, atmosfera, drustveni kontekst.
  hronologija.md     Vremenska osa — i dogadjaji pre pocetka knjige.
  zaplet.md          Struktura, tacke preokreta, kraj.
  glas-i-stil.md     POV, glagolsko vreme, ton, pravila proze, uzorci recenica.
  dnevnik-odluka.md  Zasto smo odlucili X i sta smo odbacili. Sprecava vrtenje u krug.
  otvorena-pitanja.md  Sve sto JOS NIJE odluceno. U ranoj fazi najvazniji fajl.

01-RUKOPIS/     ← sama knjiga. Jedan fajl po poglavlju: 01-naslov.md, 02-naslov.md...
02-SKICE/       ← odbacene scene, alternativne verzije, sirove ideje. Nista se ne brise.
```

## Redosled rada

1. **premisa.md** — dok ovo nije jasno, ne pise se nista drugo.
2. **likovi.md** + **svet.md** — paralelno, hrane jedno drugo.
3. **zaplet.md** — ukljucujuci kraj. Kraj se zna pre prve recenice.
4. **glas-i-stil.md** — zakljucava se kroz probno poglavlje.
5. **01-RUKOPIS/** — tek sada.

## Napomena o prevodu

Posto rukopis ide na engleski kasnije: igre reci, dijalekt i idiomi tesko prezivljavaju prevod.
Slika, ritam scene i struktura prezivljavaju sve. Gde god je moguce, nositi znacenje slikom
a ne dosetkom.
