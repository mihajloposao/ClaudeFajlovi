# Slobodno vreme

Stvari van faksa, posla i zdravlja. Trenutno: filmovi i serije.

## Struktura

- [`Filmovi i serije.md`](Filmovi%20i%20serije.md) — log odgledanog: utisci,
  ocene, šta je i nije radilo. Puni se kroz razgovor (Claude pita, Mihajlo
  odgovara), služi kao osnova za buduće preporuke.
- [`Ukus i pojmovi.md`](Ukus%20i%20pojmovi.md) — Mihajlovi sopstveni termini
  (npr. "produženi film") i obrasci u ukusu izvučeni iz loga, da se ne mora
  ceo log ponovo čitati za analizu.
